# Много бригад: синтетическое UI-демо

Запуск: `python -m backend.web`, затем открыть `http://127.0.0.1:4173`
и нажать «Демо: 30 бригад». Контракты `plan-input` / `plan-output` не менялись.

## Данные

`examples/synthetic-ui-30-300.json`: 30 автомобильных бригад, 300 заявок,
61 координатная точка на юго-востоке Москвы. Имена, заявки, загрузка и координаты
сгенерированы, файлы заказчика не использованы. Первые 30 заявок закреплены
за разными бригадами для заполнения интерфейса; часть заявок требует отсутствующего
навыка, чтобы проверить неназначенные работы. Это не оценка качества оптимизации.

Воспроизведение: `python scripts/generate_ui_demo.py`.
Для другого объёма: `python scripts/generate_ui_demo.py --crews 60 --orders 600 --output examples/custom-ui-demo.json`.
Другой файл можно импортировать, но он не включается автоматически в публичное
дорожное демо. Не перезаписывайте встроенную фикстуру реальными данными.

Матрица поездок синтетическая: расстояние по координатам × 1.3, скорость
25 км/ч, минимум 3 минуты. Поэтому километры/минуты плана не равны геометрии OSRM.
Постоянная подпись в шапке отмечает тестовые данные и время поездок.

## Работа с интерфейсом

- Над картой нет списка имён, который разрастается с числом бригад.
- Справа поиск по имени/ID, фильтр занятости, страницы по 20 бригад.
- Заявки: поиск и фильтры по всему набору, страницы по 50 строк.
- Выбор бригады показывает её дорожный маршрут, порядковые номера остановок,
  карточку и одну строку сменного графика.
- «Все бригады» показывает пути всех бригад: сразу схемы, затем дорожную
  геометрию по очереди. Счётчик показывает готовые пути; по линии можно выбрать
  бригаду. При большом наборе точки рисуются Canvas-маркерами.
- Гант: кнопки «−» / «+» (50–400%, 100% = 240 px/час), «Вся смена»,
  горизонтальная прокрутка с закреплёнными названиями и шкалой времени.
- До ответа сервиса видна пунктирная схема; при ошибке она остаётся явно
  помеченной схемой. Повтор доступен отдельной кнопкой. Смена выбора отменяет
  ожидание старого запроса и не позволяет его ответу подменить текущий маршрут.

## Публичный OSRM: только демо

Параметр `demo=sample|synthetic` в `/api/route` разрешает внешний запрос
только для точных координат соответствующей встроенной фикстуры. Импорт JSON
сбрасывает этот режим. URL внешнего сервиса нельзя задать из запроса.
Передаются только координаты и режим передвижения, не имена и не содержимое заявок.
Матрица плана через публичный сервис не рассчитывается.

В режиме бригады запрашивается один маршрут; в общем режиме — все последовательно.
Ответы кэшируются (до 200), внешний поток ограничен одним запросом за 1.05 секунды.
Поэтому первое открытие 30 маршрутов без кэша занимает как минимум около 30 секунд.
Длинные маршруты делятся на
части по 25 точек. В браузере ожидание каждого маршрута ограничено 12 секундами, на сервере —
8 секундами на внешний запрос. Сервис может отказать или быть недоступен;
для рабочих данных нужен локальный OSRM.

Источники: [OSRM Route API](https://project-osrm.org/docs/v5.24.0/api/),
[правила публичного demo server](https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server).
