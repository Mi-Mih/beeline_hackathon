# Ручная live-демонстрация

## Подготовка

Production по-прежнему использует локальный OSRM: `ROUTING_MATRIX_MODE=gateway`
(значение по умолчанию). Без доступного gateway новый сервер откажет в расчёте;
автоматической подмены дорожной матрицы приближённой нет.

Для встроенного тестового набора без локального OSRM в PowerShell:

```powershell
$env:ROUTING_MATRIX_MODE = 'input'
python -m backend.web
```

Для демо с бесплатным внешним поиском адресов: `./scripts/start-demo.ps1`.
Скрипт устанавливает `GEOCODING_MODE=public_demo`, `ROUTING_MATRIX_MODE=input`.
Поиск новых адресов работает через публичный Nominatim, **не на данных клиентов**.
По умолчанию обычный запуск без этой переменной сохраняет локальный геокодер.

Открыть `http://127.0.0.1:4173/`. Тестовый план рассчитывается при открытии.
Метрики основаны на готовой матрице, а геометрия встроенной синтетики — на
публичном OSRM. Дорожная карта требует сети. В этом окружении без установленного
OR-Tools используется обозначенный в шапке `greedy-local-search` fallback.

## Короткий сценарий на 2–3 минуты

1. Открыть небольшой встроенный набор: 4 заявки, 2 инженера. Нажать
   «Все бригады», дождаться дорожных путей. «Вся смена» показывает обзор Ганта.
2. Открыть REQ-1. Анна имеет навык подключения, автомобиль и router;
   работа начинается в 10:00 внутри окна 10:00–12:00. У Бориса нет требуемого
   автомобиля и router. REQ-4 не назначена из-за отсутствующего навыка спутникового ТВ.
3. Оставить время события **17.08.2026, 09:00 (Москва)**. «Создать заявку»:
   номер `LIVE-001`, адрес **Перервинский б-р, 21**, вид **Авария**,
   приоритет **Срочный**, длительность **30 минут**, окно **09:00–10:00**.
   Навык аварийных работ и repair-kit подставятся автоматически.
   Длительность здесь намеренно изменена с нормативных 80 минут для короткой
   тестовой работы; это демонстрационный ввод, не новый норматив.
4. «Сохранить заявку». В списке статус «Ожидает расчёта», метрики остаются 3/4,
   действующие назначения не меняются. Можно создать несколько заявок до расчёта.
5. Отдельно нажать **«Пересчитать»**. В текущем fallback LIVE-001 назначается
   Борису, REQ-2 сдвигается с 10:00 на 10:15. Справа видны добавление заявки,
   изменение времени/порядка и сравнение пробега/минут. На карте и Ганте — новый план.
   При другом солвере конкретный порядок может отличаться; ориентироваться на ответ.
6. При необходимости выбрать заявку, объяснить назначение; экспортировать план.
   «Вернуть исходный план» начинает демонстрацию заново.

## Семантика и ограничения

- Черновики хранятся в памяти вкладки, не в БД. При закрытии вкладки с черновиками
  браузер предупреждает; после перезапуска они не восстанавливаются.
- До успешного ответа расчёта сохраняются старый план и черновики. При ошибке
  можно повторить запрос или удалить черновик в его карточке.
- Смена набора, сброс и ручное назначение блокируются, пока есть
  черновики: сначала рассчитать или удалить их. «Демо-события» открывается и
  объясняет причину запрета применения, с кнопкой перехода к пересчёту. Это
  не загрузка карты. Экспорт выдаёт последний план,
  а не ещё не рассчитанные заявки.
- Время события задаётся явно в Москве (UTC+3), не берётся из сегодняшней даты.
  Его нельзя сдвигать назад после расчёта. Завершённые/начатые работы исключаются
  из будущих выездов и правильно подписываются в изменениях, не как отменённые.
  Заявка закрепляется уже с планового прибытия (включая ожидание окна), а инженер
  освобождается только по окончании этой работы. Это модель по расписанию:
  фактических статусов «прибыл»/«начал» от мобильного клиента пока нет.
  Ручное переназначение, отмена и демо-исключение инженера также проверяют эту
  границу; незавершённая текущая работа остаётся закреплённой.
- Метрики сравнивают оставшиеся работы, а не всю прежнюю смену. Прошедшие дуги
  удаляются из базы сравнения; это не обещание оптимальности или фактической экономии.
- Адрес вводится текстом; подсказки известных адресов необязательны. «Найти»
  ищет сначала в текущем наборе, затем в настроенном геокодере. Результат надо
  выбрать явно; изменение адреса сбрасывает ранее выбранные координаты.
  Можно указать широту/долготу вручную. Новую точку можно сохранить в любом
  режиме, но пересчёт новых координат требует `gateway`: готовая матрица `input`
  не содержит новых дуг. При отказе черновик сохраняется. После успешного
  расчёта новой точки публичное demo-routing отключается, геометрию запрашивают
  только у локального gateway. Реальные координаты в публичный OSRM не уходят.
- Клик по блоку Ганта показывает маршрут от старта до выбранной заявки
  включительно, без последующих остановок. Подпись карты содержит номер и время.
  Клик по бригаде возвращает полный маршрут, «Все бригады» — обзор.
- Формат заявки и `plan-output/1.0` не менялись. `/api/planning-config` сообщает
  режим матрицы и нормативы для формы, без сетевых обращений к поставщикам карт.
- Сводка справа показывает добавления, назначения, отказы, перенос времени,
  порядок, завершение/работу и отмену. Дорожные пути могут догружаться после плана.
- Исправлено ожидание загрузки карты после обновления источников: повторные
  расчёты используют уже завершённую начальную загрузку. `loaded()` может снова
  стать false при изменении источников ([MapLibre API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/#loaded)).

Проверки: `node --test tests/frontend.test.cjs` и
`python -m unittest tests.test_live_api tests.test_replan tests.test_select tests.test_demo_routing`.

## Локальный поиск адресов

Интеграция рассчитана на самостоятельно развёрнутый Nominatim с импортом OSM
региона. Используется [официальный Search API](https://nominatim.org/release-docs/latest/api/Search/)
(`search?q=…&format=jsonv2&limit=8`). OSRM строит дороги, но не заменяет геокодер.

```powershell
$env:LOCAL_GEOCODER_URL = 'http://127.0.0.1:4190'
$env:ROUTING_MATRIX_MODE = 'gateway'
$env:ROUTING_GATEWAY_URL = 'http://127.0.0.1:4180'
python -m backend.web
```

Эти переменные **подключают уже запущенные сервисы**, а не устанавливают их.
Установка и импорт Nominatim: [официальное руководство](https://nominatim.org/release-docs/latest/admin/Installation/).
На проверенном рабочем компьютере 27.09.2026 порты 4180 и 4190 не слушались;
полноценный поиск произвольных адресов и пересчёт новых координат пока не проверены
на реальном локальном графе. Проверен адаптер с локальным тестовым сервером.

`POST /api/geocode` принимает `{ "query": "город, улица, дом" }`, возвращает
`{ "source": "local", "results": [{ "address": "…", "latitude": 55.7, "longitude": 37.7 }] }`.
Пустой список — нет совпадений; 400 — неверный запрос; 503 — сервис недоступен.
Тайм-аут сервера 6 секунд, клиента 10 секунд. Ошибка предлагает ручные координаты.
Разрешён только loopback-адрес; proxy-переменные и HTTP-перенаправления отключены.
Для изолированного Docker backend сервис должен быть доступен в его сетевом
пространстве loopback (или через локальный туннель). Публичного fallback нет.
Адрес передаётся в теле POST и не попадает в обычный HTTP access log backend.
Подложка карты и CDN — отдельные сетевые зависимости; это не полностью офлайн-UI.

## Бесплатный поиск для демо

По решению владельца проекта включён отдельный режим `GEOCODING_MODE=public_demo`.
Адрес передаётся публичному Nominatim только после «Найти»; при печати запросов
нет. В форме показаны предупреждение о передаче адреса, атрибуция OSM/ODbL и
[правила сервиса](https://operations.osmfoundation.org/policies/nominatim/).
Разрешены публичные тестовые адреса, не клиентские или конфиденциальные данные.
Не использовать для массового геокодирования, фонового обхода, production-трекинга.

- Endpoint по умолчанию: `https://nominatim.openstreetmap.org/search`.
  Можно заменить через `PUBLIC_GEOCODER_URL` на совместимый HTTPS Search API
  без изменений интерфейса. `GEOCODING_MODE=local` отключает внешние обращения.
- Серверный User-Agent идентифицирует проект. Между некэшированными запросами
  не менее 1,1 секунды для приложения; параллельные запросы отклоняются.
- Кэш на диске `.runtime/geocoding.sqlite3`, до 1000 результатов на 30 дней,
  включая пустые ответы. Путь задаёт `GEOCODER_CACHE_PATH`. Файл не попадает в Git.
  Ограничитель частоты сохраняется между перезапусками. При сбое провайдера
  пауза 60 секунд, автоматического повтора нет. Запускать одну демо-инсталляцию,
  не распределять запросы по независимым серверам/кэшам.
- Контракт `/api/geocode` прежний; `source` теперь `local` либо `public_demo`.
- Доступность бесплатного API не гарантирована. Поиск известного адреса работает
  из текущего набора, кэш переживает перезапуск; остаётся ручной ввод координат.
- Это не включает внешний расчёт дорожной матрицы для произвольных координат.
  Публичный OSRM по-прежнему разрешён только для встроенных синтетических точек.
