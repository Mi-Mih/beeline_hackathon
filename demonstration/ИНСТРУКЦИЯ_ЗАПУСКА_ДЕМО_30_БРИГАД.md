# Запуск демо на 30 бригад

Инструкция предназначена для локального запуска готового
синтетического сценария: **30 бригад и 300 заявок**.
Данные заказчика в демо не используются. Docker и локальный OSRM
для этого сценария не нужны.

## Что понадобится

- папка с проектом;
- Python 3.12 или новее;
- доступ в интернет при первой установке зависимостей;
- современный браузер: Chrome, Edge или Firefox.

Все команды ниже нужно выполнять **из корневой папки проекта**,
где находятся каталоги `backend`, `frontend`, `examples` и файл
`pyproject.toml`.

## Windows 10/11

1. Открыть PowerShell в корневой папке проекта.
2. Один раз создать окружение и установить зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
```

3. Запустить демо:

```powershell
.\scripts\start-demo.ps1
```

Если PowerShell запрещает запуск `.ps1`, выполнить эквивалентные
команды в том же окне:

```powershell
$env:GEOCODING_MODE = "public_demo"
$env:ROUTING_MATRIX_MODE = "input"
python -m backend --host 127.0.0.1 --port 4173
```

## Linux/macOS

1. Открыть терминал в корневой папке проекта.
2. Один раз создать окружение и установить зависимости:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

3. Запустить демо:

```bash
GEOCODING_MODE=public_demo ROUTING_MATRIX_MODE=input \
  python -m backend --host 127.0.0.1 --port 4173
```

## Как открыть демо

1. Дождаться в терминале сообщения о запуске сервера.
2. Открыть в браузере <http://127.0.0.1:4173>.
3. Нажать **«Демо: 30 бригад»**.
4. Дождаться расчёта. В интерфейсе должны появиться 30 бригад,
   300 заявок, маршруты, метрики и сменный график.

Для показа удобно:

- выбрать отдельную бригаду и показать её маршрут и график;
- нажать **«Все бригады»** для общей карты;
- использовать поиск и фильтры по бригадам и заявкам;
- нажать **«Вся смена»**, чтобы показать полный график.

Первая загрузка дорожных линий для всех бригад может занять
около 30 секунд и требует интернет. Если внешний картографический сервис
недоступен, расчёт и график останутся доступны, а карта покажет
схематические линии.

## Проверка и остановка

Для быстрой проверки открыть в браузере:

```text
http://127.0.0.1:4173/api/health
```

Ожидаемый ответ:

```json
{"status":"ok","contract":"plan-output/1.0"}
```

Для остановки вернуться в окно с запущенным сервером и нажать
`Ctrl+C`. Повторная установка зависимостей при следующем запуске не нужна.
В новом окне терминала нужно лишь снова перейти в корень проекта,
активировать `.venv` и выполнить команду запуска.

## Типовые проблемы

**Команда `py -3.12` не найдена.**  
Установить Python 3.12 с <https://www.python.org/downloads/>. В Windows при
установке включить добавление Python в `PATH`.

**PowerShell не активирует `.venv`.**  
Открыть PowerShell от имени обычного пользователя и выполнить только
для текущего окна:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

**Порт 4173 занят.**  
Закрыть другой экземпляр демо. Либо запустить сервер на другом
порту, например `--port 4174`, и открыть
<http://127.0.0.1:4174>.

**Карта не загрузилась.**  
Проверить доступ в интернет. Даже без подложки карты можно показать
расчёт, списки бригад и заявок, метрики и сменный график.

> Важно: режим `public_demo` предназначен только для тестовых адресов.
> Не вводите в нём клиентские или конфиденциальные данные.
